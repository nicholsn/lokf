# LOKF documentation site

This Astro Starlight site publishes the LOKF guide, specification, API reference,
and an interactive view of `examples/acme-knowledge/`. Starlight supplies sitewide
full-text search. The graph page uses the same graph explorer shipped in the
`lokf new` knowledge-base template, with graph data generated by `lokf export`.

## Build

From the repository root, install the Python toolkit with `uv sync --locked`.
Then run:

```sh
cd web
npm ci
npm run build
```

The prebuild step runs `lokf export` on the reference bundle, generates the API
reference, and copies shared documentation and schema artifacts into the site.
The static output is in `web/dist/`. Use `npm run dev -- --background` to
preview changes, then `npm run astro -- dev status` or `npm run astro -- dev stop`
to inspect or stop the background server.

Edit the Markdown or MDX files in `src/content/docs/` for authored guide text.
Edit `README.md` or `SPEC.md` at the repository root for sections imported by
`scripts/sync-content.mjs`; the files in `src/generated/` are build outputs.

The graph explorer's shared component lives in
`../src/lokf/templates/kb/src/components/GraphExplorer.astro`. The
`sync:graph` step copies it and its helpers into `src/generated/graph-explorer/`,
so the docs page exercises the same controls as a generated site.
