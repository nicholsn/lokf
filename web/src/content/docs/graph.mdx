Every edge below is an **RDF predicate** drawn from a concept's typed
frontmatter relations — labels like `prov:wasDerivedFrom`, `dcterms:requires`,
or `lokf:measures`. Plain markdown links in a concept's *body* are **not**
edges: only the typed relations that project to RDF triples appear here, so
this graph is exactly the concept-to-concept subset of the bundle's RDF
projection.

The data is the Acme knowledge bundle — eight concepts, twelve typed relations.
(`run-on-bq`, the executor Reference, is reached by a computation's `executor`
rather than a typed relation, so it sits on its own.) This page uses the same
graph explorer as sites created with `lokf new`. The reference bundle is small
enough to show in full; larger sites open a bounded concept neighborhood.

Choose a layout to examine connections, inferred communities, concept types,
or visible hubs. Node and relation filters change the displayed subgraph, and
the list view lets you inspect the same concepts without the canvas. Click a
concept to see its typed connections and open its source. The path finder
traces a shortest chain between two visible concepts; its direction option
respects relation arrows. The URL preserves your current view for sharing.
Graph search highlights *labels and IDs* in this view;
the documentation site's header search indexes the guide's full text.
